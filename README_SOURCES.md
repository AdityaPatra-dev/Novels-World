## 6. Key Global Search & Extraction Milestones

1. **True Multi-Source Global Search**:
   - Concurrently broadcasts queries across all 36 registered sources with isolated timeouts (`8s`) and token cancellation.
   - Live stream updates UI as each source responds.
   - Dual view modes: `Grouped Titles` and `By Source`.
2. **Relevance Ranking Engine**:
   - Canonical exact title matches receive `+20,000` priority score.
   - Multi-source availability adds `+500` points per source.
   - Fanfiction, adaptation, and spin-off titles are heavily demoted (`-5,000` points).
   - Real-time suggestions bar provides instant autocomplete on keystroke.
   - Persistent recent search history with one-tap recall and quick clear.
3. **Data-SRC Cover Image Priority & Global SSL Override**:
   - Extracted cover URLs from `data-src` and `data-original` before falling back to `src`.
   - Sanitized cover URLs with URI encoding and origin resolution.
   - Initialized `AppHttpOverrides` in `main.dart` so Flutter's `Image.network` never fails on missing intermediate SSL certificates.
4. **Resilient Novel Detail Title Extraction**:
   - Filtered title extraction through `TextCleaner.isValidNovelTitle(cand, url)` to prevent genre tags (`Fantasy`, `Action`) from replacing the novel title.
